# AGATE: From Concept to MVP — Presentation Deck

An interactive, cyberpunk-styled presentation deck and companion PowerPoint presentation detailing the architecture, design, and implementation journey of **AGATE by TURFINGO**.

---

## 🌟 Highlights

- **Interactive Presentation Viewport**: Built with modern CSS grid/glows, Orbitron typography, and sleek cyberpunk aesthetic.
- **PowerPoint Companion**: Includes `agate_presentation.pptx` and automated PowerShell build script `build-pptx.ps1`.
- **Slide Navigation**: Keyboard controls and interactive slide navigation for showcasing technical milestones, system architecture, and MVP results.

---

## 🚀 Getting Started

### View in Browser
You can open `index.html` directly in any modern browser, or run the local helper script:

```powershell
.\serve-presentation.ps1
```

### Build / Update PPTX
```powershell
.\build-pptx.ps1
```
