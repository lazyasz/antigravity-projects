# AI & Machine Learning Lab: Data Manipulation and Visualization

A comprehensive collection of Python scripts covering fundamental Data Science, Numerical Computing, Data Wrangling, and Visualization workflows using NumPy, Pandas, and Matplotlib.

---

## 📚 Topics Covered

1. **NumPy Fundamentals**:
   - Array creation, slicing, indexing, and arithmetic operations
   - Statistical operations and binary file I/O (.npy)
2. **Pandas Data Wrangling**:
   - Series and DataFrame operations
   - CSV & Excel file I/O
   - Handling missing values (`dropna`, `fillna`), cleaning datasets (Diabetes exploration)
3. **Data Visualization**:
   - Bar charts (simple, grouped), Line charts, Stack plots
   - Histograms, Pie charts, Box plots, and Scatter plots
4. **Interactive Dashboard**:
   - `dashboard.py` for comprehensive data exploration and visualization.

---

## 🚀 Getting Started

### Requirements
```bash
pip install numpy pandas matplotlib seaborn
```

### Run Scripts
Execute any topic script directly:
```bash
python 01_numpy_creation.py
python dashboard.py
```
