# 🎮 Family Feud Interactive Game Board & Navshakti 2026 Question Bank

An interactive, broadcast-style **Family Feud Game Board** web application built with modern web technologies, dynamic audio synthesizers / sound effects, real-time strike tracking, and comprehensive round question banks designed for live college events, festivals, and competitions (Navshakti 2026).

---

## ✨ Features

- **Dynamic Interactive Board**: Authentic game-show style card flipping animations, score tallying, and strike counters (X, XX, XXX).
- **Sound Effects Engine**: Web Audio API sound synthesis and SFX for correct reveals, buzzer strikes, round wins, and timer countdowns.
- **Navshakti 2026 Question Bank**: Embedded multi-round trivia question banks spanning engineering, college life, pop culture, and sports with top survey answers.
- **Host / Admin Controls**: Built-in control console to award points, reveal answers individually or all at once, assign strikes, and switch rounds.
- **Responsive Layout**: Designed for projectors, large displays, laptops, and mobile screens.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to launch the game board.

---

## 🛠️ Build for Production

```bash
npm run build
```

The output will be generated in the `dist/` directory, ready for deployment on Vercel, Netlify, or GitHub Pages.
