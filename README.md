## 🚀 Quick Start Highlights

### 🏎️ Formula 1 Data Warehouse & Telemetry Simulator
```bash
cd f1-data-warehouse
# Run the automated OLAP analytical suite
python run_olap_suite.py

# Launch the live telemetry server & web dashboards
python server.py
# Open dashboard.html or powerbi_f1.html in your browser
```

### 🎯 DebtScope Platform
```bash
cd debtscope-predictive-engineering/backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### 🎮 Family Feud Interactive Board
```bash
cd family-feud-board
npm install
npm run dev
# Visit http://localhost:5173
```

### 🤖 Evoke Discord Bot
```bash
cd evoke-discord-bot
npm install
npm run build
npm start
```
