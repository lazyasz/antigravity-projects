# Navigated Command Center

A real-time command, dispatch, and situational awareness platform built with React, TypeScript, Tailwind CSS, Express, Drizzle ORM, and WebSocket architecture.

---

## ⚡ Key Features

- **Real-Time Operational Map**: Live tracking, dispatch routes, geofencing, and situational intelligence.
- **Incident & Resource Management**: Dynamic ticketing, status updates, team assignment, and audit logs.
- **Modern UI / UX**: Built with Tailwind CSS, Radix UI primitives, Lucide icons, and interactive charts (Recharts).
- **Type-Safe Backend**: Express API server with Drizzle ORM and schema validation via Zod.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Radix UI, Lucide Icons, Recharts, Wouter routing
- **Backend**: Node.js, Express, TypeScript (tsx), Drizzle ORM, WebSocket
- **Tooling**: Vite, Vitest, Prettier, TypeScript

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
# or
pnpm install
```

### 2. Database Migration & Push
```bash
npm run db:push
```

### 3. Run Development Server
```bash
npm run dev
# or on Windows
.\start_all.bat
```

### 4. Build for Production
```bash
npm run build
npm start
```
