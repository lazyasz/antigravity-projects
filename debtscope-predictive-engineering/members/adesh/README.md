# Adesh's Subsystem: Executive Web Dashboard & Visual Analytics

## 🎯 Scope of Work
- **Subsystem**: `frontend/`
- **Application Type**: React 19 Single Page Application (SPA)
- **Key Visual Modules**: KPI Health Cards, 4-Quadrant Priority Matrix, File Intelligence, AI Copilot Shell
- **Core Technologies**: React 19, Vite, TailwindCSS 4, Recharts, Lucide Icons, Axios

## 📂 Subsystem Modules
1. `dashboard.jsx`: Executive overview with KPI cards, health score, debt hours, and predicted defect rate.
2. `priority_matrix.jsx`: Interactive Recharts 2D scatterplot plotting Business Value against Remediation Effort.
3. `file_intelligence.jsx`: Deep-dive component displaying file cyclomatic complexity, churn, and author entropy.
4. `api_service.js`: Resilient Axios service layer with automated mock fallback.
5. `SPEAKING_NOTES.md`: Script & "Why This vs Why Not That" defense for Review 2.
